# Test Idea: PipelineWatch

No-code monitoring dashboard for data pipelines. Automatically detects anomalies, data quality issues, and pipeline failures. Integrates with popular ETL tools (Airflow, dbt, Fivetran).

## Additional Context

- Target: Data engineers and analytics teams at mid-market companies
- Problem: Pipeline failures discovered too late, data quality issues reach dashboards
- Current solutions: Custom alerting, expensive enterprise tools (Monte Carlo, Atlan)
- Revenue model: Usage-based pricing ($0.10 per monitored table/day)
- Competition: Monte Carlo ($$$), Atlan, Bigeye, Great Expectations (open source)
