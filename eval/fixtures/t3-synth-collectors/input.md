# Test Idea: SynthCollective

A curated marketplace and community for vintage synthesizer collectors. Features authenticated listings with provenance tracking, expert forums for repair advice, and escrow-protected transactions.

## Additional Context

- Target: Serious vintage synth collectors (own 3+ vintage instruments)
- Spend: $2,000+/year on equipment
- Current pain: eBay fraud, no authentication, fragmented Facebook groups
- Revenue model: 10% seller commission + premium memberships
- Competition: eBay, Reverb.com, Facebook Marketplace
