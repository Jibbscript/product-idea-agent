# Competitive Analysis Framework

Detailed framework for analyzing competitive landscapes.

## Competitor Categories

### Direct Competitors
Solve the same problem for the same customer.

**Criteria:**
- Same core problem addressed
- Same target customer segment
- Would appear in same buying decision
- Similar pricing/business model

### Indirect Competitors
Solve the same problem differently.

**Criteria:**
- Address the same underlying need
- Different approach or technology
- May target adjacent segments
- Partial feature overlap

### Alternatives
Other ways customers solve the problem.

**Types:**
- **DIY**: Spreadsheets, manual processes
- **Services**: Consultants, agencies
- **Adjacent tools**: Broader platforms with some functionality
- **Status quo**: Doing nothing / living with the problem

## Feature Matrix Template

Create a matrix comparing key features across competitors:

| Feature | Us | Comp A | Comp B | Comp C | Priority |
|---------|------|--------|--------|--------|----------|
| Core Feature 1 | ✅ | ✅ | ✅ | ❌ | Must Have |
| Core Feature 2 | ✅ | ✅ | ❌ | ✅ | Must Have |
| Differentiator 1 | ✅ | ❌ | ❌ | ❌ | Differentiator |
| Nice to Have 1 | ❌ | ✅ | ✅ | ✅ | Low |

**Legend:**
- ✅ = Has feature
- ⚠️ = Partial/limited
- ❌ = Missing
- 🔜 = On roadmap

## Competitive Intensity Score

Calculate overall market competitiveness:

| Factor | Weight | Score (1-5) | Weighted |
|--------|--------|-------------|----------|
| Number of competitors | 20% | | |
| Funding levels | 20% | | |
| Feature parity | 20% | | |
| Market concentration | 15% | | |
| Barrier to entry | 15% | | |
| Rate of change | 10% | | |

**Scoring Guide:**

| Factor | 1 (Low) | 3 (Medium) | 5 (High) |
|--------|---------|------------|----------|
| Number | 1-2 | 5-10 | 15+ |
| Funding | Mostly bootstrapped | Mix | Multiple $50M+ |
| Feature parity | Wide gaps | Some gaps | All similar |
| Concentration | Fragmented | 2-3 leaders | 1 dominant |
| Barrier | Easy to enter | Moderate | Hard to enter |
| Rate of change | Slow/stable | Moderate | Fast/volatile |

## Win/Loss Analysis Questions

Understand why customers choose competitors:

### Win Factors (Why We Win)
- What made us stand out?
- What deal-breaker did competitors have?
- What was the deciding factor?

### Loss Factors (Why We Lose)
- What feature were we missing?
- What concern couldn't we overcome?
- Who did they choose and why?

## Differentiation Strategies

### Category Creation
- Define a new category you can own
- Reframe the problem
- Example: "Revenue Operations" vs "Sales Tools"

### Specialization
- Focus on a specific vertical or use case
- Go deeper than horizontal competitors
- Example: "HR software for restaurants"

### Technology
- Leverage new technology (AI, etc.)
- Better architecture or approach
- Example: "AI-native from day one"

### Experience
- Dramatically better UX
- Faster time-to-value
- Example: "Get started in 2 minutes"

### Pricing
- Disruptive pricing model
- Better value at same price
- Example: "Unlimited seats, flat rate"

### Integration
- Better ecosystem fit
- Native integrations
- Example: "Built for Shopify stores"

## Red Flags in Competitive Landscape

**Warning signs to note:**

1. **No competitors**: Either blue ocean or no market
2. **All competitors failing**: Market may not exist
3. **Single dominant player**: Hard to displace
4. **Recent well-funded entrant**: Race may be on
5. **Platform expanding in**: Risk of getting eaten
6. **Commoditized features**: Differentiation will be hard
7. **Low switching costs**: Customers may churn to you—or away
